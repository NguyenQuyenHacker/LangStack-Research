# Langfuse Observability — Features

Langfuse có 27 feature quanh tracing. Thay vì đọc theo thứ tự sidebar (Essential/Advanced — phân loại theo mức độ phổ biến), bộ file này gom lại **theo nội dung**: các feature cùng giải quyết một loại vấn đề nằm chung một file. Mỗi feature được nói lại ở mức tóm gọn — đủ hiểu bản chất và cách dùng cơ bản, không đào sâu như một trang tài liệu riêng.

Trang này là bản đồ. Bảy file nội dung, mỗi file một nhóm:

| File | Nhóm | Gom feature nào |
|---|---|---|
| `01-05-01-trace-organization.md` | Tổ chức & định danh trace | Sessions, User Tracking, Trace IDs & Distributed Tracing |
| `01-05-02-labeling-attributes.md` | Thuộc tính gắn nhãn | Environments, Tags, Metadata, Releases & Versioning |
| `01-05-03-structure-content.md` | Cấu trúc & nội dung observation | Observation Types, Agent Graphs, Multi-Modality, Token & Cost Tracking |
| `01-05-04-data-masking.md` | Bảo mật dữ liệu | Masking |
| `01-05-05-operations.md` | Vận hành: khối lượng & hành vi gửi | Sampling, Log Levels, Event queuing/batching |
| `01-05-06-annotation-feedback.md` | Phản hồi & chú thích | Comments, Corrections, User Feedback |
| `01-05-07-search-integrations.md` | Tìm kiếm trên UI & tích hợp | Filter Search Bar, Full-Text Search, Chart any table, MCP Tracing, Trace URLs, Pulse, Agent Access, Web Callouts |

## Toàn bộ 27 feature — một dòng mỗi cái

**Nhóm 1 — Tổ chức & định danh trace** → `01-05-01`

| Feature | Lo việc gì |
|---|---|
| Sessions | Gom nhiều trace thành một chuỗi tương tác (thread chat, workflow nhiều bước) |
| User Tracking | Gắn end-user vào trace, mở khoá per-user view |
| Trace IDs & Distributed Tracing | Đặt trace ID tùy chỉnh/tất định, nối trace qua nhiều service |

**Nhóm 2 — Thuộc tính gắn nhãn** → `01-05-02`

| Feature | Lo việc gì |
|---|---|
| Environments | Tách dữ liệu theo môi trường: production, staging, development |
| Tags | Nhãn bất biến, gán lúc tạo, lọc theo chiều nghiệp vụ |
| Metadata | Key-value linh hoạt cho ngữ cảnh không thuộc tên/input/output |
| Releases & Versioning | Theo dõi tác động thay đổi ứng dụng lên metric (A/B test) |

**Nhóm 3 — Cấu trúc & nội dung observation** → `01-05-03`

| Feature | Lo việc gì |
|---|---|
| Observation Types | 10 loại observation mang ngữ nghĩa riêng (generation, tool, agent...) |
| Agent Graphs | Vẽ luồng agent thành đồ thị, suy ra từ type + nesting |
| Multi-Modality | Trace dữ liệu đa phương thức: ảnh, audio, file đính kèm |
| Token & Cost Tracking | Ghi model, token, chi phí trên generation |

**Nhóm 4 — Bảo mật dữ liệu** → `01-05-04`

| Feature | Lo việc gì |
|---|---|
| Masking | Che dữ liệu nhạy cảm (PII, số thẻ) trước khi trace rời ứng dụng |

**Nhóm 5 — Vận hành** → `01-05-05`

| Feature | Lo việc gì |
|---|---|
| Sampling | Chỉ gửi một tỷ lệ trace, giảm chi phí/nhiễu ở tải cao |
| Log Levels | Gán DEBUG/DEFAULT/WARNING/ERROR cho observation, lọc theo mức độ |
| Event queuing/batching | Gom trace thành batch, gửi nền; `flush()` cho ứng dụng chạy ngắn |

**Nhóm 6 — Phản hồi & chú thích** → `01-05-06`

| Feature | Lo việc gì |
|---|---|
| Comments | Ghi chú cộng tác trên trace/observation/session, có @mention và reaction |
| Corrections | Ghi lại output đúng lẽ ra model phải trả, làm dữ liệu fine-tuning |
| User Feedback | Thu phản hồi người dùng cuối (thumbs up/down, sao) gắn vào trace |

**Nhóm 7 — Tìm kiếm trên UI & tích hợp** → `01-05-07`

| Feature | Lo việc gì |
|---|---|
| Filter Search Bar | Lọc bảng bằng cách gõ một dòng text thay vì lắp filter sidebar |
| Full-Text Search | Tìm toàn văn trong input/output của trace/observation |
| Chart any table | Chuyển bảng observation thành biểu đồ trên cùng một query |
| MCP Tracing | Nối trace client và server của Model Context Protocol thành một |
| Trace URLs | Lấy link trực tiếp tới một trace để chia sẻ/ghi log |
| Pulse | (chưa đọc sâu — liên quan monitor/alert trên boolean score) |
| Agent Access | (chưa đọc sâu — cấp quyền truy cập cho agent) |
| Web Callouts | (chưa đọc sâu) |

**Ngoài phạm vi Observability** (thuộc section khác, chỉ nhắc): Query Data, Metrics API, Custom Dashboards — cả ba có dấu ↗ trên sidebar, thuộc nhóm API & Data Platform và Metrics.

## Đọc theo thứ tự nào

Người mới nên đọc `01-03-concepts` và `01-04-best-practices` trước — hai file đó đã giảng sâu bản chất của nhiều feature ở đây (mô hình trace/observation/session, observation types, cách gắn attribute). Các file trong thư mục này bổ sung chi tiết cách dùng từng feature, tóm gọn.

Ba mục `(chưa đọc sâu)` không phải kiến thức bắt buộc — tài liệu chính thức nói rất ít, sẽ đào khi công việc cần.
