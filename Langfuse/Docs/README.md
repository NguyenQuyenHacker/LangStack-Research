# Langfuse Docs — Research Hub

Repo này đào sâu **tab Docs** trên langfuse.com (phiên bản v4), viết bằng tiếng Việt cho kỹ sư đã biết Python và có kinh nghiệm với LangChain.

---

## Định vị Langfuse

**Langfuse** là nền tảng vận hành và kiểm soát chất lượng cho ứng dụng LLM — đứng cạnh bot để theo dõi, đo chi phí, quản lý prompt, chấm điểm; **không viết ra bot** và **không chạy bot** thay mình.

---
