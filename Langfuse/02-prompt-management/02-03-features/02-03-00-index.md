# Prompt Management — Features

Langfuse Prompt Management có 16 feature quanh việc soạn, phiên bản hoá, phục vụ và tự động hoá prompt. Bộ file này gom theo nội dung thay vì theo thứ tự sidebar: các feature cùng giải quyết một loại vấn đề nằm chung một file. Mỗi feature được nói lại ở mức tóm gọn — đủ hiểu bản chất và cách dùng cơ bản, không đào sâu như một trang tài liệu riêng.

Trang này là bản đồ. Năm file nội dung, mỗi file một nhóm:

| File | Nhóm | Gom feature nào |
|---|---|---|
| `02-03-01-dynamic-authoring.md` | Soạn prompt động | Variables, Message Placeholders, Prompt Composability, Config |
| `02-03-02-versioning-deployment.md` | Phiên bản hoá & triển khai | Version Control (versions/labels/protected labels), A/B Testing, Folders |
| `02-03-03-runtime-reliability.md` | Độ tin cậy lúc runtime | Caching, Guaranteed Availability |
| `02-03-04-iteration-observability.md` | Lặp thử & quan sát | Playground, Link to Traces (+ cross-ref Prompt Experiments) |
| `02-03-05-automation-integrations.md` | Tự động hoá & tích hợp | Agent Access, MCP Server, Webhooks & Slack, GitHub Integration, n8n Node |

## Toàn bộ feature — một dòng mỗi cái

**Nhóm 1 — Soạn prompt động** → `02-03-01`

| Feature | Lo việc gì |
|---|---|
| Variables | Chèn chuỗi động vào text/chat prompt bằng <code v-pre>{{var}}</code>, thay qua `.compile()` |
| Message Placeholders | Chèn nguyên một mảng message (ví dụ lịch sử chat) vào vị trí cố định trong chat prompt |
| Prompt Composability | Một prompt tham chiếu prompt khác bằng tag `@@@langfusePrompt:...@@@`, tránh lặp nội dung (chỉ áp dụng cho text prompt) |
| Config | JSON object tùy ý đi kèm mọi prompt, lưu model params/response format, đóng băng cùng version |

**Nhóm 2 — Phiên bản hoá & triển khai** → `02-03-02`

| Feature | Lo việc gì |
|---|---|
| Version Control | Lưu snapshot immutable của prompt, gắn label (con trỏ đổi được) để đánh dấu version đang triển khai, khoá label quan trọng bằng protected labels |
| A/B Testing | Gán label khác nhau cho nhiều version, client chọn ngẫu nhiên để so sánh hiệu suất trên traffic thật |
| Folders | Tổ chức tên prompt thành cây thư mục bằng dấu `/`, thuần UI, không ảnh hưởng runtime |

**Nhóm 3 — Độ tin cậy lúc runtime** → `02-03-03`

| Feature | Lo việc gì |
|---|---|
| Caching | Cache prompt phía client theo TTL (mặc định 60s, stale-while-revalidate), giảm mọi lần gọi sau về gần như tức thời |
| Guaranteed Availability | Đảm bảo `get_prompt()` không lỗi khi cache miss và mạng fail, qua pre-fetch lúc khởi động hoặc giá trị `fallback` khai báo sẵn |

**Nhóm 4 — Lặp thử & quan sát** → `02-03-04`

| Feature | Lo việc gì |
|---|---|
| Playground | Thử/so sánh biến thể prompt ngay trong UI trước khi deploy |
| Link to Traces | Gắn trace/generation về đúng phiên bản prompt để theo dõi metric sau khi chạy thật |

Prompt Experiments (chạy một prompt qua dataset để đánh giá hàng loạt) thuộc phạm vi nhánh Evaluation, chỉ được nhắc một câu và cross-link ở `02-03-04`, không viết sâu ở đây.

**Nhóm 5 — Tự động hoá & tích hợp** → `02-03-05`

| Feature | Lo việc gì |
|---|---|
| Agent Access | Cho agent/coding assistant lấy, tạo, sửa prompt qua Agent Skill, MCP Server, hoặc CLI/API |
| MCP Server | Expose thao tác prompt thành tool cho agent — cùng trang docs với Agent Access, không có trang kỹ thuật riêng |
| Webhooks & Slack | Báo real-time (POST + HMAC signature) khi phiên bản prompt được tạo/sửa/xoá |
| GitHub Integration | Đồng bộ prompt vào GitHub qua repository_dispatch hoặc webhook auto-commit |
| n8n Node | Community node lấy prompt Langfuse vào workflow n8n |

## Đọc theo thứ tự nào

Người mới nên đọc `02-03-concepts` trước — file đó giảng bản chất prompt object, version, label. Các file trong thư mục này bổ sung chi tiết cách dùng từng feature, tóm gọn.

`02-03-05` (MCP Server) có một cờ cần verify: docs `features/mcp-server` và `features/agentic-access` trả về cùng một trang nội dung, chưa có tài liệu kỹ thuật riêng (tool/endpoint, config JSON) cho MCP Server trong phạm vi Prompt Management.
